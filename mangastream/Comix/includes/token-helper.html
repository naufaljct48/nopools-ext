🔑 Comix.to Token Helper

Get your API token for Paperback extension

STEP 1

Open Safari and go to comix.to. Open any manga page (e.g. comix.to/title/93q1r).

STEP 2

Copy the bookmarklet code below. Create a new bookmark in Safari and paste this as the URL/Address:

javascript:void((function(){var o=XMLHttpRequest.prototype.open;XMLHttpRequest.prototype.open=function(m,u){if(u&&u.indexOf('/chapters')>-1){var t=(u.match(/[?&]_=([^&]+)/)||[])[1];if(t){prompt('Copy this token:',t)}}return o.apply(this,arguments)};var f=window.fetch;window.fetch=function(u,opts){var url=typeof u==='string'?u:u.url;if(url&&url.indexOf('/chapters')>-1){var t=(url.match(/[?&]_=([^&]+)/)||[])[1];if(t){prompt('Copy this token:',t)}}return f.apply(this,arguments)};alert('Token interceptor active! Now scroll down to load chapters, or refresh the page.')})())
STEP 3

While on the manga page, tap the bookmark you just created. You'll see an alert saying "Token interceptor active!"

STEP 4

Scroll down on the manga page (or refresh) to trigger chapter loading. A prompt will appear with your token — Select All → Copy.

STEP 5

Go back to Paperback → Comix.to Settings and paste the token in the "API Token" field.

⚠️ Note: Token expires after a few hours (tied to your Cloudflare session). When chapters stop loading, repeat these steps to get a fresh token.
